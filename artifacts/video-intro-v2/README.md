# Form — revised introduction

Deliverable: `form-intro-v2.mp4` (1920×1080, 24 fps, approximately 17 seconds).

This is an illustrated introduction built from the project's actual JSCAD models
and Boolean comparison results. It is not a recording of the app or a live AI
response. The movement is an illustrative transition between saved model shapes.

Narration uses the stock `af_heart` voice from Kokoro, generated locally. It is
synthetic speech, not the project creator's voice or an imitation of a celebrity.
- Speech engine and setup: https://github.com/thewh1teagle/kokoro-onnx
- Model and stock voices: https://huggingface.co/hexgrad/Kokoro-82M

Music is an original synthesized instrumental generated by `make_music.py`.
It includes warm keyboard chords, plucked notes, bass and light percussion;
no third-party recordings or music samples are used. The music is lowered
beneath speech. Isolated voice, music and mixed WAVs remain editable.

Reproduction:
1. `node --import tsx artifacts/video-intro-v2/meshes.ts`
2. Run `make_audio.py` with kokoro-onnx, numpy and soundfile installed, with the
   model and voices at the temporary locations specified in the script.
3. Run `make_music.py`, then `render.py` (Pillow, numpy, ffmpeg required).

Script and sentence timing are stored in `timing.json`. The screenshots document
representative shots. The earlier draft is preserved in `../video-intro/`.
